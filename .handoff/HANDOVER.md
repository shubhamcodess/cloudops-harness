## 3. Architecture as built (monorepo, TypeScript, pnpm, vitest, XState v5, Zod v4)

- contracts: Zod schemas = the typed handoffs: RepoProfile, Requirements, Sku, Candidate/CostModel, LedgerEntry, Decision, GeneratedFile, SecretsManifest, ProofReport, RunStage/RunView.
- engine: hash-chained Ledger; DecisionEngine (RuleBackend, LlmChoiceBackend with injected `complete`, CompositeEngine -> human when confidence<0.8); planQuestions/applyAnswers (asks only missing fields); XState pipeline machine INGEST..DELIVER with REVIEW requiring APPROVE. 23 tests pass.
- detectors: `detectRepo(path)` deterministic RepoProfile; fixtures/ has 10 repos (static-site, node-api, python-api, npm-package, mcp-server, ai-agent, rag-app, monorepo-microservices, pii-app, java-monolith). 19 tests pass.
- pricing: live normalized SKUs. AWS bulk Price List CSV (no key), GCP Cloud Billing Catalog API (GCP_API_KEY), Azure Retail (no key); 24h disk cache `.cache/pricing`; `loadPriceBook`; CLI `tsx packages/pricing/src/cli.ts aws eu-west-1 'm5\.large'`. 8 tests pass. - policy: regions+RTT tables, GDPR/residency (`allowedRegions`, `complianceReport`), `buildCandidates`, `decide` (hard filters then cheapest, deterministic). 14 tests pass at last check.
- app: `analyze(path, req)` glue and `adaptPriceBook` (maps policy service names to pricing names); `demo.ts`.
- iac-gen: `generateArtifacts` -> Dockerfile, Terraform (aws-ecs-fargate, aws-lambda, aws-s3-cloudfront, gcp-cloud-run, gcp-gcs-cdn, RDS/Cloud SQL), Helm chart (+ExternalSecret, NetworkPolicy, HPA, PDB), GitHub Actions (OIDC), OPA rego policies, floci override. 12 tests pass (tofu validate on 5 archs, helm lint/template, conftest).
