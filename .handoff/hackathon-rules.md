# Hackathon rules (condensed)
- 18+, in-person Bengaluru. Teams 1-4 (solo ok). Must be able to code.
- Built during the hackathon; pre-built projects ineligible.
- Agent MUST run on TrueForge. Any language/framework/model provider.
- AI assistants allowed; disclose in README; must explain own architecture and code.
- Agent must reach a real system/tool; generated code runs in a sandbox; stops for human approval before irreversible actions.
- Only own accounts/data/credentials. No keys in repo or demo video.
- Respectful conduct. Participants keep IP; organizers may ask to showcase.

Theme: Agents That Act. Idea list: Cloud Cost Janitor, Migration Rehearsal Agent, Release Captain, Ticket Resolver, Access Reviewer, Runbook Executor.
See ideas.md.
